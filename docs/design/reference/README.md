# Design Reference Index

Эта папка хранит скриншоты для аудита и редизайна «Вместе Вкуснее».

## Правило использования Dodo-референсов

Dodo Pizza используется как UX-бенчмарк зрелости: структура каталога, плотность карточек, sticky-навигация, корзина, модальные окна, адресный flow, checkout, профиль и футер.

Нельзя копировать код, CSS, ассеты, тексты, логотипы, фирменные иллюстрации, точные анимации, точную раскладку и брендовые элементы Dodo.

Цветовое правило: Dodo-оранжевый и его производные не переносить. Везде заменять их на фирменный красно-розовый акцент «Вместе Вкуснее» (`--vv-orange`, сейчас `#ca7767`) и его мягкие производные. Не заменять этот акцент зеленым.

Текущее направление проекта: строгий лаконичный food-commerce. Белый/светло-серый фон, темный текст, фирменные красно-розовые CTA, реальные фото еды, чистая сетка, без градиентов, орбов, bokeh, glassmorphism и случайных декоративных карточек.
