# UI/UX Audit: Current Design Direction

Дата: 2026-07-07

## Current Decision

Старый аудит от 2026-06-30 больше не является дизайн-направлением. Его выводы про `warm`, `soft`, `premium family Italian`, кремовые фоны, basil/terracotta акценты и декоративный hero считаются устаревшими.

Актуальное направление: строгий лаконичный food-commerce уровня зрелой доставки. Белый/светло-серый фон, темный текст, фирменные красно-розовые CTA (`--vv-orange`, сейчас `#ca7767`), реальные фото еды, плотная сетка, короткие тексты, без градиентов.

Dodo-референсы использовать только для UX-зрелости и композиционной ясности. Dodo-оранжевый не переносить: заменять на фирменный красно-розовый акцент, не на зеленый.

## What Is Now Considered A Problem

- Любой новый `linear-gradient`, `radial-gradient`, `conic-gradient`.
- Декоративные орбы, bokeh, glow, glassmorphism.
- Слишком крупные “hero cards” в рабочих интерфейсах.
- Случайные плашки, наклейки, бейджи без функции.
- Кремовый лендинг вместо строгой commerce-страницы.
- Смешение старых `.site-*` и новых визуальных подходов без единого токена.
- Тяжелая темная админка, если она не помогает работе смены.
- Партнерский кабинет как копия админки вместо финансового кабинета.

## Public Site Risks

- Hero может снова стать декоративным лендингом. Нужен строгий первый экран: еда, короткий текст, понятные CTA.
- SEO/info blocks должны быть как последний аккуратный footer block: заголовок и компактные колонки.
- Семейность и ресторанность показывать через контент и фото, не через декоративный стиль.

## Catalog / Checkout Risks

- Каталог должен начинаться быстро, без длинной промо-ленты.
- Категории sticky.
- Карточки товаров компактные и сканируемые.
- Checkout должен быть формой заказа, не промо-страницей.
- Disabled buttons должны объяснять причину.

## Admin Risks

- Заказы должны быть первым рабочим объектом.
- Менеджер и администратор отличаются по роли, но остаются на `/admin`.
- Никаких декоративных hero и градиентных панелей.

## Partners Risks

- Главное: промокод, скидка, комиссия, доставленные заказы, начисления, выплаты.
- Стиль как финансовый кабинет: строго, спокойно, читаемо.

## QA Criteria

- No new gradients in touched files.
- No old warm decorative direction.
- Build passes.
- Responsive checks: 375, 390, 768, 1024, 1440.
- Order/admin/payment/auth logic remains intact.
- No Dodo copy.
